# coke_africa_frontend

Coke Africa MaxDiff dashboard, served at `/coke-africa/`: Benefits Dashboard,
Benefits Platform Dashboard and CokeAI. Forked from `coke_eu_frontend`
(the `/cokeasp` app); talks to the same `coke_eu` backend with region `AFRICA_OU`.

    npm ci && npm run dev      # http://localhost:5174
    bash deploy.sh             # on web-prod: build and copy to /var/www/html/coke-africa/build
